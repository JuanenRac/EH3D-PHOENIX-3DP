# Support

* **A problem or a wrong result:** write to electrohobby3d@gmail.com with the file (or the smallest one that shows it), the command you ran and what you expected.
* **A question or an idea:** the same address, or an issue in this repository.
* **A printer that works (or does not) with a profile:** an issue with the form "Hardware validation result": this is how a profile becomes verified.
* **A vulnerability:** privately, see `SECURITY.md`.
